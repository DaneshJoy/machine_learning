# یادگیری ماشین

دورهٔ «یادگیری ماشین» برای مرکز جهاد دانشگاهی صنعتی شریف است.

- `contents/` صفحه‌های درس است.
- `codes/` نوت‌بوک‌هایی است که از گیت‌هاب پیوند می‌شوند.

```sh
npm ci
npm run check
# پیش‌نمایش لوکال (ساخت + سرور روی http://localhost:3000):
npm run dev
```
