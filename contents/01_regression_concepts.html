رگرسیون خطی و KNN — regression_synthetic_data
y = 2 + 4x + noise

داده را از یک تابع خطی می‌سازیم و نویز گاوسی (میانگین ۰، انحراف معیار ۳) به آن اضافه می‌کنیم تا شبیه داده واقعی شود؛ مدل باید خط پنهان را از دل نویز پیدا کند. ورودی X در scikit-learn باید دوبعدی باشد (reshape(-1, 1)).

کد نمونه
import numpy as np
N = 50
X = np.linspace(0, 5, N).reshape(-1, 1)    # (50, 1)
y_true = 2 + 4*X
y_noisy = y_true + np.random.normal(0, 3, X.shape)
نمایش خروجی — داده ورودی
LinearRegressionKNeighborsRegressor

رگرسیون خطی با روش کمترین مربعات، خطی را می‌یابد که مجموع مربع خطاها را کمینه کند؛ مدلی پارامتری با دو پارامتر (عرض از مبدأ و شیب). KNN چیزی «یاد نمی‌گیرد»: پیش‌بینی هر نقطه، میانگین هدفِ K همسایه نزدیک آن است (اینجا K=3)، پس خروجی پله‌ای و حساس به نویز است.

کد نمونه
from sklearn.linear_model import LinearRegression
from sklearn.neighbors import KNeighborsRegressor

lr_model = LinearRegression()
knn_model = KNeighborsRegressor(n_neighbors=3)

lr_model.fit(X, y_noisy)
knn_model.fit(X, y_noisy)

print(lr_model.intercept_, lr_model.coef_)
# [2.19] [[3.65]]   ← نزدیک به 2 و 4
نمایش خروجی — برازش دو مدل
predict

مدل را روی دو نقطه‌ی جدید (که ندیده) آزمایش می‌کنیم. چون تابع بدون نویز را می‌دانیم، مقدار واقعی در دسترس است و خطای هر مدل قابل مقایسه است. ساختار داده واقعاً خطی است، پس خط معمولاً از KNN دقیق‌تر درمی‌آید.

کد نمونه
X_new = np.array([[1.75], [3.25]])
y_new = 2 + 4*X_new          # مقدار واقعی

pred_lr = lr_model.predict(X_new)
pred_knn = knn_model.predict(X_new)

چندجمله‌ای، Pipeline و ارزیابی — regression_synthetic_data_2
y = 0.5x³ − 2x² + x + 3

این بار تابع واقعی درجه 3 است؛ یک خط راست نمی‌تواند آن را مدل کند. مجموعه ۳۰۰ نقطه با نویز (انحراف معیار ۵) روی بازه [−۴, ۵] ساخته می‌شود.

کد نمونه
N = 300
x_raw = np.linspace(-4, 5, N)
y_raw = 0.5*x_raw**3 - 2*x_raw**2 + x_raw + 3
y_noisy = y_raw + np.random.normal(0, 5, size=N)
X = x_raw.reshape(-1, 1)
نمایش خروجی — داده و تابع واقعی
train_test_split

داده را به دو بخش تقسیم می‌کنیم: آموزش (۸۰٪) برای یادگیری و آزمون (۲۰٪) برای سنجش روی داده‌ای که مدل هرگز ندیده است. تنها با این کار می‌توان تعمیم‌پذیری مدل را سنجید.

کد نمونه
from sklearn.model_selection import train_test_split
X_train, X_test, y_train, y_test = train_test_split(
    X, y_noisy, test_size=0.2)
print('Train:', len(X_train))   # 240
print('Test:', len(X_test))     # 60
نمایش خروجی — نقاط آموزش و آزمون
StandardScaler

ویژگی‌ها را استاندارد می‌کنیم: z = (x − μ) / σ؛ میانگین ۰ و انحراف معیار ۱. μ و σ فقط از داده آموزش محاسبه (fit) و سپس روی هر دو بخش اعمال (transform) می‌شود تا اطلاعات آزمون به مدل نشت نکند.

کد نمونه
from sklearn.preprocessing import StandardScaler
scaler = StandardScaler()
scaler.fit(X_train)                 # فقط روی آموزش
X_train_s = scaler.transform(X_train)
X_test_s = scaler.transform(X_test)
print(scaler.mean_, scaler.scale_)

Pipeline

Pipeline مراحل پیش‌پردازش و مدل را به‌صورت یک زنجیره درمی‌آورد: با یک fit و یک predict همه مراحل به‌ترتیب اجرا می‌شوند و مقیاس‌دهی خودکار فقط روی داده آموزش fit می‌شود. در رگرسیون چندجمله‌ای، PolynomialFeatures ویژگی‌های x², x³، … را می‌سازد و مدل خطی روی آن‌ها اجرا می‌شود؛ یعنی مدل در پارامترها خطی است ولی منحنی می‌سازد.

کد نمونه
pipelines = {
  'Linear Regression': Pipeline([
      ('scaler', StandardScaler()),
      ('model', LinearRegression())]),
  'Polynomial Regression': Pipeline([
      ('poly', PolynomialFeatures()),

منحنی پیش‌بینی هر مدل روی یک شبکه‌ی x نرم. خط راست نمی‌تواند خمیدگی را بگیرد (underfit)؛ چندجمله‌ای منحنی می‌سازد؛ درخت و جنگل تصادفی پله‌ای‌اند اما انعطاف‌پذیر و بدون فرض درباره‌ی شکل تابع.

کد نمونه
x_plot = np.linspace(-4, 5, 400).reshape(-1, 1)

نمایش خروجی — منحنی مدل‌ها
MAE · MSE · R²

MAE: میانگین قدر مطلق خطا (هم‌واحد با y). MSE: میانگین مربع خطا؛ به خطاهای بزرگ حساس‌تر است. R²: سهمی از تغییرات y که مدل توضیح می‌دهد (۱ = عالی، نزدیک ۰ = ضعیف). محاسبه روی داده آزمون انجام می‌شود.

کد نمونه
from sklearn.metrics import (mean_absolute_error,
    mean_squared_error, r2_score)

y_pred = pipe.predict(X_test)
mae = mean_absolute_error(y_test, y_pred)
mse = mean_squared_error(y_test, y_pred)
r2 = r2_score(y_test, y_pred)

Actual vs Predicted

هر نقطه یک نمونه آزمون است: محور افقی مقدار واقعی و محور عمودی پیش‌بینی مدل. مدل ایده‌آل روی خط مورب (y = x) قرار می‌گیرد؛ پراکندگی بیشتر از خط یعنی خطای بیشتر.

کد نمونه
for ax, (name, pipe) in zip(axes, trained.items()):

    ax.scatter(y_test, y_pred)
    lims = [min(y_test.min(), y_pred.min()),
